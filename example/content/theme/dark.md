`prefers-color-scheme`, and nothing else. There is no toggle, because the
reader's machine already knows the answer and a toggle is one more thing to
remember across pages and machines.

Switch your system appearance while this page is open and it changes under you.

## What changes

The six tokens, and nothing else: ink and page swap ends, the rule and the code
panel move with them, and the link colour lightens enough to hold contrast on a
dark page. Layout, type and spacing are identical in both.

## Pictures in the dark

Artwork drawn on white is the hard case. A cover or a hero keeps its own
border and sits on the page colour, so it reads as a plate on the page rather
than a hole in it, and a mark drawn as SVG — like this site's — can carry the
same media query internally and answer the scheme itself.
